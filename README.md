# FEED-Errors
FEED Errors

## Обязательные правила заполнения Feed Amazon

- **Brand** — при заполнении Feed бренд дополнительно проставляется на **все SKU**.
- **Tax code**:
  - **US** — `A_GEN_TAX`
  - **EU** — `A_GEN_Standard`

При исправлении ошибок Feed эти значения тоже должны быть сохранены (не удалять и не заменять другими).
